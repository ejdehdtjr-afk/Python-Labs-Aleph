참고: `C:/Users/user/Python-Lab-ALeph-T/_7_board_test`의 Flask 게시판 구조를 참고하여 이 폴더에 독립 구현했습니다. 원본 MySQL 데이터나 외부 공공 API는 복사하지 않았습니다.

## 실행

이 폴더에서 실행합니다.

```powershell
python -m pip install -r requirements.txt
python -m flask --app app:create_app seed-demo
python app.py
```

현재 작업 환경에는 vendor 폴더로 Flask가 설치되어 있습니다. 이 환경에서 실습 계정을 초기화하려면 `python -c "from app import create_app; create_app().test_cli_runner().invoke(args=['seed-demo'])"`도 가능합니다.

접속: http://127.0.0.1:5000

실습 계정: `normal`(일반 0), `gold`(골드 1), `admin`(관리자 2). 공통 비밀번호 `CafeTest123!`. seed-demo는 명시적으로 실행할 때만 계정을 만들고 기존 계정을 덮어쓰지 않습니다. 공개 배포용 계정이 아닙니다.

## 제출 화면 확인 순서

1. 회원가입 후 로그인: 헤더의 회원명과 일반(0)을 확인합니다.
2. 일반 계정에서 골드 및 관리자 링크: HTTP 403, 현재 권한과 필요 권한을 확인합니다.
3. 골드 계정: 골드 페이지 200, 관리자 페이지 403을 확인합니다.
4. 관리자 계정: 관리자 화면에서 DB id, 회원명, role을 확인합니다. 회원명을 수정하고 일반 회원을 골드로 변경합니다.
5. 다른 브라우저에서 로그인 중인 해당 회원의 골드 페이지를 새로고침하면 변경이 즉시 반영됩니다. 일반으로 내리면 403입니다.
6. 관리자가 해당 회원을 삭제하면 다음 요청은 401입니다. 해당 회원의 게시글도 함께 삭제됩니다.
7. 로그아웃 상태에서 보호 페이지를 열면 401입니다.

관리자는 골드 페이지에 접근할 수 있는 계층형 권한입니다. 현재 관리자 본인 계정은 수정·삭제를 막아 실습 중 관리자 부재를 방지합니다. 모든 변경은 POST + CSRF 검증을 적용합니다. 서버 재시작 시 기존 로그인 세션은 만료됩니다.

DB: 이 폴더의 `board.db`, users 테이블의 role은 기본값 0, 허용 값 0/1/2입니다. 비밀번호는 해시로 저장합니다. 관리자 화면은 비밀번호를 제외한 실제 DB 조회 결과를 표시합니다.

검증: `python test_access.py`
